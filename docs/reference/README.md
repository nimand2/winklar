# Externe Referenzen

`sius-shooter-number-barcode.pdf` ist das vorhandene SIUS-Supportdokument zur
Schützennummer und Barcodebildung. Die Datei dient als fachliche Referenz und
wird nicht von der Anwendung geladen. Dieser Ordner wird nicht verpackt.

`SiusData.pdf` wurde vom Betreiber als SIUS-Datenformatspezifikation bereitgestellt.
Seite 39 beschreibt `Ins_Del`: `1` ist manuell eingefügt, `2` ist ignorieren.
Die Anwendung bewahrt dieses Importkennzeichen unverändert und führt den lokalen
Löschstatus separat. Die PDF ist Referenzmaterial, kein Anwendungscode.
